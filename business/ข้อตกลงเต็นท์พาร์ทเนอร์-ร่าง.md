## ข้อ 1. คำนิยาม
1.1 **“ผู้ขาย”** หมายถึง เจ้าของรถหรือผู้มีสิทธิ์ขายรถ ซึ่งติดต่อรถไวเพื่อขายรถ \
1.2 **“ข้อมูลรถ”** หมายถึง รายละเอียดและรูปภาพรถที่รถไวส่งให้พาร์ทเนอร์เพื่อเสนอราคา \
1.3 **“ข้อเสนอ”** หมายถึง ราคารับซื้อที่พาร์ทเนอร์เสนอต่อรถไวสำหรับรถคันใดคันหนึ่ง \
1.4 **“ผู้ช่วยขาย”** หมายถึง พนักงานหรือตัวแทนของรถไวที่ดูแลผู้ขายและประสานงานการขาย \
1.5 **“การซื้อสำเร็จ”** หมายถึง กรณีที่พาร์ทเนอร์ หรือบุคคลที่เกี่ยวข้องกับพาร์ทเนอร์ตามข้อ 7.2 ได้ซื้อ รับโอน หรือได้มาซึ่งรถคันที่รถไวส่งข้อมูลให้ ไม่ว่าทั้งหมดหรือบางส่วน

## ข้อ 2. ขอบเขตบริการ
2.1 รถไวจะส่งข้อมูลรถที่ผ่านการตรวจเอกสารเบื้องต้นให้พาร์ทเนอร์ เพื่อพิจารณาเสนอราคา \
2.2 รถไวเป็น **ผู้ประสานงานและแนะนำ** เท่านั้น **ไม่ใช่คู่สัญญาในการซื้อขายรถ** การซื้อขายรถเป็นสัญญาระหว่างผู้ขายกับพาร์ทเนอร์โดยตรง \
2.3 รถไวไม่รับประกันจำนวนรถที่จะส่งให้พาร์ทเนอร์ และไม่รับประกันว่าผู้ขายจะเลือกข้อเสนอของพาร์ทเนอร์ \
2.4 พาร์ทเนอร์มีสิทธิ์เลือกเสนอราคาเฉพาะรถที่สนใจ โดยไม่มีข้อผูกมัดต้องเสนอทุกคัน

## ข้อ 3. หน้าที่ของรถไว
3.1 ตรวจสอบเอกสารเบื้องต้น (ความตรงกันของชื่อในเล่มทะเบียนกับบัตรประชาชน และข้อมูลรถกับเล่ม) ก่อนส่งข้อมูลรถ ทั้งนี้ การตรวจสอบดังกล่าว **ไม่ใช่การรับรองความถูกต้องสมบูรณ์** ของรถหรือเอกสาร \
3.2 ส่งข้อมูลรถตามที่ผู้ขายให้มาโดยสุจริต และแจ้งข้อบกพร่องที่ผู้ขายแจ้งไว้ \
3.3 สรุปข้อเสนอให้ผู้ขายอย่างเป็นธรรม และแจ้งผลให้พาร์ทเนอร์ทราบ \
3.4 จัดให้มีผู้ช่วยขายประสานการนัดตรวจรถและการโอนกรรมสิทธิ์

## ข้อ 4. หน้าที่ของพาร์ทเนอร์
4.1 เสนอราคาโดยสุจริตภายในเวลาที่รถไวกำหนด และส่งข้อเสนอผ่านช่องทางที่รถไวกำหนดเท่านั้น \
4.2 ตรวจสภาพรถและเอกสารด้วยตนเองก่อนตัดสินใจซื้อ พาร์ทเนอร์รับผิดชอบการตัดสินใจซื้อของตนเอง \
4.3 หากจะลดราคาจากข้อเสนอเดิมหลังตรวจรถ ต้องแจ้งเหตุผลที่ตรวจพบจริงต่อผู้ขายและผู้ช่วยขาย \
4.4 **ชำระเงินค่ารถให้ผู้ขายโดยตรง** เข้าบัญชีของผู้ขาย (หรือผู้มีสิทธิ์รับเงินตามกฎหมาย เช่น ไฟแนนซ์ในกรณีปิดยอด) ห้ามชำระผ่านผู้ช่วยขายหรือบุคคลอื่น \
4.5 ดำเนินการโอนกรรมสิทธิ์และปิดยอดไฟแนนซ์ (ถ้ามี) ให้ถูกต้องตามกฎหมาย \
4.6 ปฏิบัติต่อผู้ขายอย่างสุภาพและเป็นธรรม ไม่ใช้วิธีการกดดันหรือให้ข้อมูลเท็จ \
4.7 แจ้งรถไวทันทีเมื่อการซื้อสำเร็จ หรือเมื่อการซื้อขายยกเลิก

## ข้อ 5. ค่าบริการ
5.1 พาร์ทเนอร์ตกลงชำระค่าบริการให้รถไว **เฉพาะเมื่อเกิดการซื้อสำเร็จ** ในอัตรา ______________ บาท (______________________ บาทถ้วน) ต่อคัน \
   [หรือเลือกแบบร้อยละ: ร้อยละ ______ ของราคาซื้อขายจริง แต่ไม่น้อยกว่า ______ บาท และไม่เกิน ______ บาทต่อคัน — ให้เลือกแบบใดแบบหนึ่งแล้วลบอีกแบบ] \
5.2 อัตราค่าบริการข้างต้น ☐ รวม ☐ ไม่รวม ภาษีมูลค่าเพิ่ม (ถ้ามี) \
5.3 พาร์ทเนอร์ต้องชำระค่าบริการ **ภายในวันที่โอนกรรมสิทธิ์หรือวันที่ส่งมอบรถ แล้วแต่อย่างใดเกิดก่อน** โดยโอนเข้าบัญชี \
   ธนาคาร ________________ ชื่อบัญชี ________________________ เลขที่บัญชี ________________ \
5.4 รถไวจะออกใบเสร็จรับเงิน/ใบกำกับภาษี (ถ้ามี) ให้พาร์ทเนอร์ภายใน ______ วันหลังได้รับชำระ \
5.5 หากพาร์ทเนอร์ชำระล่าช้า ยินยอมเสียค่าปรับในอัตรา ______ บาทต่อวัน หรือดอกเบี้ยตามอัตราที่กฎหมายกำหนด และรถไวมีสิทธิ์ระงับการส่งข้อมูลรถจนกว่าจะชำระครบ \
5.6 ค่าบริการนี้เป็นภาระของพาร์ทเนอร์ทั้งหมด **ห้ามเรียกเก็บหรือหักจากราคาที่จ่ายให้ผู้ขาย**

## ข้อ 6. การติดต่อผู้ขาย
6.1 ในขั้นเสนอราคา พาร์ทเนอร์จะได้รับเฉพาะข้อมูลรถ ไม่ได้รับชื่อหรือข้อมูลติดต่อของผู้ขาย \
6.2 เมื่อผู้ขายเลือกข้อเสนอของพาร์ทเนอร์และยินยอมแล้ว รถไวจะเปิดเผยข้อมูลที่จำเป็นเพื่อนัดตรวจรถและโอนรถ \
6.3 การนัดหมายตรวจรถและโอนรถ ให้ประสานผ่านผู้ช่วยขาย และผู้ช่วยขายมีสิทธิ์เข้าร่วมทุกขั้นตอน

## ข้อ 7. การห้ามติดต่อข้ามหัว (Non-Circumvention)
7.1 พาร์ทเนอร์ตกลงว่าจะไม่ติดต่อ ชักชวน หรือทำการซื้อขายกับผู้ขายที่รู้จักผ่านรถไวโดยตรงหรือผ่านบุคคลอื่น โดยไม่ผ่านรถไว สำหรับรถคันที่รถไวส่งข้อมูลให้ **เป็นระยะเวลา ______ เดือน** นับแต่วันที่รถไวส่งข้อมูลรถคันนั้น [แนะนำ 6–12 เดือน] \
7.2 ข้อ 7.1 ให้ใช้บังคับรวมถึงการซื้อผ่านพนักงาน หุ้นส่วน ญาติ บริษัทในเครือ หรือบุคคลใดที่ทำการแทนพาร์ทเนอร์ \
7.3 หากฝ่าฝืนข้อ 7.1 พาร์ทเนอร์ตกลงชำระค่าบริการตามข้อ 5 สำหรับรถคันนั้น พร้อมค่าเสียหายเพิ่มเติมจำนวน ______ เท่าของค่าบริการ [ควรให้นักกฎหมายพิจารณาความเหมาะสมของจำนวนเบี้ยปรับ] และรถไวมีสิทธิ์บอกเลิกข้อตกลงนี้ทันที

## ข้อ 8. ความรับผิดชอบเกี่ยวกับรถและการซื้อขาย
8.1 ข้อมูลรถมาจากผู้ขาย รถไวส่งต่อโดยสุจริต แต่ **ไม่รับประกัน** สภาพรถ ประวัติรถ เลขไมล์ หรือความถูกต้องของเอกสาร พาร์ทเนอร์ต้องตรวจสอบเองก่อนซื้อ \
8.2 ข้อพิพาทเกี่ยวกับสภาพรถ ราคา การชำระเงิน หรือการโอนกรรมสิทธิ์ ระหว่างผู้ขายกับพาร์ทเนอร์ ให้เป็นความรับผิดชอบของคู่ซื้อขาย ทั้งนี้รถไวจะช่วยประสานงานโดยสุจริต \
8.3 หากพาร์ทเนอร์พบหรือสงสัยว่ารถหรือเอกสารมีปัญหาทางกฎหมาย (เช่น รถโจรกรรม เอกสารปลอม) ให้หยุดการซื้อขายและแจ้งรถไวทันที

## ข้อ 9. ข้อมูลส่วนบุคคลและการรักษาความลับ
9.1 พาร์ทเนอร์จะใช้ข้อมูลส่วนบุคคลของผู้ขายที่ได้รับจากรถไว **เพื่อการตรวจรถ ชำระเงิน และโอนกรรมสิทธิ์ของรถคันนั้นเท่านั้น** และปฏิบัติตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 \
9.2 พาร์ทเนอร์จะไม่นำข้อมูลผู้ขายไปใช้ทางการตลาด ขาย หรือเปิดเผยต่อบุคคลอื่น เว้นแต่กฎหมายกำหนด \
9.3 พาร์ทเนอร์ต้องเก็บรักษาข้อมูลรถ ข้อเสนอของพาร์ทเนอร์รายอื่น (ถ้าทราบ) และเงื่อนไขในข้อตกลงนี้เป็นความลับ \
9.4 พาร์ทเนอร์ห้ามนำรูปรถหรือข้อมูลรถที่ได้รับจากรถไวไปโพสต์หรือเผยแพร่ ก่อนที่การซื้อสำเร็จและพาร์ทเนอร์เป็นเจ้าของรถแล้ว

## ข้อ 10. ระยะเวลาและการบอกเลิก
10.1 ข้อตกลงนี้มีผลตั้งแต่วันที่ลงนาม และมีผลต่อไปจนกว่าฝ่ายใดฝ่ายหนึ่งบอกเลิก \
10.2 ฝ่ายใดฝ่ายหนึ่งอาจบอกเลิกได้โดยแจ้งเป็นลายลักษณ์อักษร (รวมถึงข้อความทาง LINE หรืออีเมล) ล่วงหน้าไม่น้อยกว่า ______ วัน \
10.3 รถไวมีสิทธิ์บอกเลิกทันที หากพาร์ทเนอร์ผิดข้อ 4.4, 5, 7 หรือ 9 \
10.4 การบอกเลิกไม่กระทบหน้าที่ชำระค่าบริการที่เกิดขึ้นแล้ว และข้อ 7 กับข้อ 9 ยังคงมีผลต่อไปตามระยะเวลาที่กำหนด

## ข้อ 12. กฎหมายที่ใช้บังคับ
ข้อตกลงนี้อยู่ภายใต้บังคับกฎหมายไทย หากมีข้อพิพาท ทั้งสองฝ่ายจะเจรจาโดยสุจริตก่อน หากตกลงกันไม่ได้ ให้ศาลไทยที่มีเขตอำนาจเป็นผู้พิจารณา
