## 0. หน้าที่ของผู้ช่วยขาย

ผู้ช่วยขายคือ **ตัวแทนของผู้ขายรถ** ตลอดการขาย ไม่ใช่ตัวแทนของเต็นท์

| ทำ | ไม่ทำ |
|---|---|
| ดูแลลูกค้าคนเดียวตั้งแต่ทักไลน์จนโอนเสร็จ | ปล่อยให้ลูกค้าคุยกับเต็นท์เองก่อนเลือกข้อเสนอ |
| ตรวจเอกสารก่อนส่งให้เต็นท์ | ส่งชื่อ/เบอร์ลูกค้าให้เต็นท์ในขั้นเสนอราคา |
| ช่วยลูกค้าได้ราคาดีที่สุดอย่างโปร่งใส | รับเงินใต้โต๊ะ หรือ "ค่าน้ำ" จากเต็นท์ |
| อยู่ด้วยวันตรวจรถและวันโอน | รับเงินค่ารถแทนลูกค้า หรือให้เงินผ่านบัญชีตัวเอง |
| อัปเดต CRM ทุกครั้งที่สถานะเปลี่ยน | สัญญาราคาหรือระยะเวลาที่ไม่แน่ใจ |

### กฎทอง 5 ข้อ (ผิดข้อใดข้อหนึ่ง = ผิดร้ายแรง)

1. **เงินค่ารถ เต็นท์โอนให้ผู้ขายโดยตรงเท่านั้น** ห้ามผ่านมือผู้ช่วยขายหรือรถไว
2. **ห้ามเปิดเผยชื่อ/เบอร์ผู้ขาย** ให้เต็นท์ จนกว่าผู้ขายเลือกข้อเสนอและยินยอมนัดตรวจรถ
3. **ห้ามรับผลประโยชน์ใดๆ จากเต็นท์** นอกจากค่าบริการที่รถไวเก็บตามข้อตกลง
4. **หยุดทันทีถ้าเอกสารไม่ตรง** (ชื่อในเล่มไม่ตรงบัตร, เลขตัวถังไม่ตรงเล่ม, เล่มดูผิดปกติ) แล้วแจ้งหัวหน้า
5. **บันทึกทุกอย่างใน CRM** ถ้าไม่ได้บันทึก = ไม่ได้เกิดขึ้น

## 2. ขั้นตอนการทำงาน 7 ขั้น

```
ลีดเข้า → ① รับเรื่อง → ② เก็บข้อมูล+รูป → ③ ตรวจเอกสาร → ④ ส่งเต็นท์
       → ⑤ สรุปข้อเสนอ → ⑥ วันตรวจรถ → ⑦ วันโอน → หลังขาย
```

### ① รับเรื่อง (สถานะ CRM: 1 → 2)

1. ลีดเข้า LINE OA → กด **Tag ชื่อตัวเอง** ในแชท (ป้องกันสองคนตอบคนเดียวกัน)
2. สร้างแถวใหม่ใน CRM ชีต "ลีด": รหัสลีด (RW-0001 เรียงต่อ), วันที่, เวลา, ช่องทาง
3. ตอบด้วยข้อความ **T1** (ดูหัวข้อ 4)
4. บันทึก "นาทีที่ตอบครั้งแรก"

### ② เก็บข้อมูลและรูป (สถานะ: 3)
ข้อมูลที่ต้องได้ครบ:

- ยี่ห้อ / รุ่น / รุ่นย่อย / ปี / สี / เกียร์
- เลขไมล์ (จากรูปหน้าปัด)
- สถานะไฟแนนซ์ + ชื่อไฟแนนซ์ + ยอดปิดโดยประมาณ (ถ้ามี)
- เขตที่จอดรถ / วันเวลาที่สะดวกให้ดูรถ
- ประวัติชน / น้ำท่วม / ซ่อมใหญ่ (ถามตรงๆ ทุกครั้ง)
- ราคาที่ลูกค้าคาดหวัง

**รูป 10 มุมที่ต้องได้ (ส่งเช็กลิสต์ให้ลูกค้าด้วยข้อความ T2):**

1. หน้าตรง  2. หลังตรง  3. ข้างซ้ายเต็มคัน  4. ข้างขวาเต็มคัน
5. เฉียงหน้าซ้าย  6. เฉียงหลังขวา  7. หน้าปัด (เห็นเลขไมล์ ติดเครื่อง)
8. เบาะหน้า  9. เบาะหลัง  10. ห้องเครื่อง
\+ รูปจุดที่มีตำหนิ (ถ้ามี)

### ③ ตรวจเอกสารเบื้องต้น (ก่อนส่งเต็นท์)
ขอรูป **หน้ารายการจดทะเบียนในเล่ม** (หรือสำเนาจากไฟแนนซ์) และ **บัตรประชาชน** (ปิดเลขหลังบัตรได้)

| ตรวจ | ผ่านเมื่อ |
|---|---|
| ชื่อเจ้าของในเล่ม | ตรงกับบัตรประชาชนของคนที่คุยด้วย หรือมีหนังสือมอบอำนาจ |
| ยี่ห้อ/รุ่น/สี/ปี ในเล่ม | ตรงกับรถในรูป |
| เลขทะเบียน | ตรงกับป้ายในรูป |
| ภาษีประจำปี | ยังไม่ขาด หรือลูกค้ารับว่าจะต่อก่อนโอน |
| รถชื่อบริษัท | ต้องมีหนังสือรับรองบริษัท + ผู้มีอำนาจลงนาม |
| รถติดไฟแนนซ์ | มีเลขสัญญา + ยอดปิดจากไฟแนนซ์ |

**🚩 สัญญาณอันตราย — หยุดและแจ้งหัวหน้าทันที:**

- ชื่อในเล่มไม่ตรง และอ้างว่า "ซื้อต่อมา ยังไม่ได้โอน" / "ผ่อนต่อจากคนอื่น"
- ไม่ยอมส่งรูปเล่มหรือบัตร แต่เร่งขายด่วนมาก
- ราคาที่ต้องการต่ำผิดปกติเมื่อเทียบกับตลาด
- รถติดไฟแนนซ์ แต่ผู้ขายไม่ใช่ผู้เช่าซื้อในสัญญา
- เลขไมล์ในรูปดูผิดปกติเมื่อเทียบกับสภาพรถ

ติ๊ก "ตรวจเล่ม+บัตรแล้ว = ใช่" ใน CRM เมื่อผ่านเท่านั้น

### ④ ส่งให้เต็นท์เสนอราคา (สถานะ: 4)

1. โพสต์ในกลุ่ม LINE เต็นท์พาร์ทเนอร์ด้วยข้อความ **D1** (ไม่มีชื่อ เบอร์ เลขทะเบียนเต็ม หรือหน้าบัตร)
2. แนบรูปรถ 10 มุม (**ห้ามแนบรูปเล่มหรือบัตรประชาชน**)
3. แจ้งเวลาปิดรับราคาชัดเจน
4. เต็นท์ตอบราคาทางแชทส่วนตัวกับผู้ช่วยขาย (ไม่ตอบในกลุ่ม) → บันทึกทุกราคาลงชีต "ราคาเสนอ"
5. เป้าหมาย: **อย่างน้อย 2 ข้อเสนอต่อคัน** ถ้าได้น้อยกว่านี้ ให้ทักเต็นท์ที่ตรงสายรถรายตัว

### ⑤ สรุปข้อเสนอให้ลูกค้า (สถานะ: 5)

1. ส่งข้อความ **T4** สรุป 2–3 ข้อเสนอสูงสุด (บอกชื่อเต็นท์ได้หลังลูกค้าสนใจ)
2. อธิบายชัดเจนว่า **ราคานี้เป็นราคาเบื้องต้น** จะยืนยันหลังเต็นท์ตรวจรถจริง
3. ช่วยต่อรองได้ 1 รอบ: แจ้งเต็นท์อันดับ 1 ว่ามีราคาแข่ง (ห้ามโกหกตัวเลข)
4. ถ้าลูกค้าตกลง → ขอความยินยอมเปิดเผยชื่อและเบอร์ให้เต็นท์ที่เลือกเพื่อนัดตรวจรถ
5. ถ้าลูกค้าไม่พอใจราคา → ขอบคุณ ปิดเป็น "9 ไม่ขาย / ราคาไม่พอใจ" แล้วติดตามอีกครั้งใน 30 วัน

### ⑥ วันตรวจรถ (สถานะ: 6)
**ก่อนไป:** ยืนยันเวลาทั้งลูกค้าและเต็นท์ 1 วันก่อน + เช้าวันนัด (ข้อความ T5)

**ที่หน้างาน:**

- [ ] ไปถึงก่อนเต็นท์อย่างน้อย 10 นาที
- [ ] ตรวจเล่มตัวจริง/บัตรตัวจริงกับเจ้าของ เทียบเลขตัวถังและเลขเครื่องกับเล่ม
- [ ] อยู่ด้วยตลอดการตรวจ จดสิ่งที่เต็นท์พบ
- [ ] ถ้าเต็นท์ลดราคาจากที่เสนอ → ต้องมีเหตุผลที่เห็นได้จริง (เช่น พบรอยชนที่ไม่ได้แจ้ง) ผู้ช่วยขายช่วยลูกค้าพิจารณา
- [ ] ตกลงราคาสุดท้ายเป็นลายลักษณ์อักษร (แชท LINE หรือใบยืนยันการซื้อรถ ภาคผนวก ข. ในข้อตกลงพาร์ทเนอร์)
- [ ] นัดวันโอน และบอกลูกค้าว่าต้องเตรียมเอกสารอะไร (ข้อความ T6)

### ⑦ วันโอน (สถานะ: 7 → 8)

- [ ] เอกสารผู้ขายครบ (เล่ม, บัตรประชาชนตัวจริง, สำเนาเซ็นรับรอง, หนังสือมอบอำนาจถ้ามี)
- [ ] รถติดไฟแนนซ์: เต็นท์ปิดยอดกับไฟแนนซ์ตามขั้นตอนของไฟแนนซ์ + โอนส่วนต่างให้ผู้ขาย มีหลักฐานทุกยอด
- [ ] **เต็นท์โอนเงินเข้าบัญชีผู้ขายโดยตรง** ผู้ขายตรวจว่าเงินเข้าจริงในแอปธนาคารก่อนส่งมอบรถ/กุญแจ
- [ ] ส่งมอบรถ กุญแจทุกดอก คู่มือ สมุดเข้าศูนย์
- [ ] ทำเอกสารโอน/ยื่นที่สำนักงานขนส่งตามขั้นตอน
- [ ] **เก็บค่าบริการรถไวจากเต็นท์ภายในวันเดียวกัน** (โอนเข้าบัญชีรถไว + ออกใบเสร็จ)
- [ ] ถ่ายรูปส่งมอบ (ขออนุญาตลูกค้าก่อนถ้าจะใช้โพสต์)
- [ ] อัปเดต CRM: เต็นท์ที่ชนะ, ราคาขายจริง, ค่าบริการ, เก็บแล้ว, วันที่โอน → สถานะ "8 ปิดดีล"

### หลังขาย

- วันเดียวกัน: ส่งข้อความขอบคุณ + **ขอรีวิว Google** (ข้อความ T7)
- 7 วันหลังโอน: ถามว่าการโอนเรียบร้อยดี + ขอให้แนะนำเพื่อน (ข้อความ T8)
- บันทึก "ขอรีวิวแล้ว = ใช่"

## 3. กรณีพิเศษ

| กรณี | ทำอย่างไร |
|---|---|
| **รถติดไฟแนนซ์ และราคาต่ำกว่ายอดปิด** | แจ้งตัวเลขส่วนต่างให้ลูกค้าชัดเจนก่อนนัดตรวจ ลูกค้าต้องเตรียมเงินส่วนต่างเอง |
| **ผู้ขายไม่ใช่เจ้าของในเล่ม** | ต้องมีหนังสือมอบอำนาจ + สำเนาบัตรเจ้าของ และยืนยันกับเจ้าของจริงทางโทรศัพท์ ถ้าไม่ได้ = หยุด |
| **รถน้ำท่วม / ชนหนัก** | แจ้งในโพสต์กลุ่มเต็นท์ตรงๆ อย่าปิดบัง เพื่อไม่ให้ราคาถูกกดตอนตรวจรถ |
| **เต็นท์ติดต่อลูกค้าข้ามหัว** | บันทึกหลักฐาน แจ้งหัวหน้า ดำเนินการตามข้อตกลงพาร์ทเนอร์ |
| **ลูกค้าไม่พอใจบริการ** | ขอโทษ ฟังให้จบ แจ้งหัวหน้าภายในวันเดียวกัน ห้ามโต้เถียงในแชท |
| **ไม่มีเต็นท์เสนอราคาเลย** | แจ้งลูกค้าตามจริงภายในเวลาที่สัญญา ทักเต็นท์ที่ตรงสายเพิ่ม หรือแนะนำให้ลองใหม่ภายหลัง |

## 4. ข้อความสำเร็จรูป (คัดลอกไปใช้ใน LINE)

**T1 — ตอบครั้งแรก** \
> สวัสดีครับคุณ{ชื่อ} ผม{ชื่อผู้ช่วยขาย} ผู้ช่วยขายรถส่วนตัวจากรถไวครับ 🐆 ผมจะดูแลรถของคุณตั้งแต่ตอนนี้จนขายเสร็จนะครับ \
> ขอข้อมูลเพิ่มนิดเดียวครับ ① รุ่นย่อย/สี ② เลขไมล์ ③ ติดไฟแนนซ์ไหม ④ รถจอดเขตไหน ⑤ ราคาที่คาดหวังไว้ประมาณเท่าไรครับ

**T2 — ขอรูป** \
> ขอรูปรถ 10 มุมนะครับ จะได้ราคาที่แม่นที่สุด 📸 \
> หน้า / หลัง / ข้างซ้าย / ข้างขวา / เฉียงหน้า / เฉียงหลัง / หน้าปัดตอนติดเครื่อง (เห็นเลขไมล์) / เบาะหน้า / เบาะหลัง / ห้องเครื่อง \
> ถ้ามีรอยหรือจุดที่ซ่อม ถ่ายมาด้วยได้เลยครับ ยิ่งบอกตรง ราคายิ่งไม่โดนกดตอนตรวจรถ

**T3 — ขอเอกสาร** \
> เพื่อความปลอดภัยของคุณเอง ขอรูปหน้ารายการจดทะเบียนในเล่ม กับบัตรประชาชนด้านหน้าครับ (ปิดเลขหลังบัตรได้) ข้อมูลนี้ใช้ตรวจสอบเท่านั้น **ไม่ส่งให้เต็นท์** ครับ

**T4 — สรุปข้อเสนอ** \
> ได้ข้อเสนอแล้วครับ 🎉 {รุ่นรถ} \
> 🥇 {ราคา 1} บาท \
> 🥈 {ราคา 2} บาท \

## 6. โครงสร้างค่าตอบแทนที่แนะนำ (ปรับได้)

- **ฐานเงินเดือนต่ำ + ค่าคอมต่อคันที่ปิดได้** — จูงใจให้ปิดดีล
- **โบนัสรีวิว 5 ดาว** — จูงใจให้ดูแลลูกค้าดี ไม่ใช่แค่ปิดเร็ว
- **ไม่มีค่าคอมจากเต็นท์โดยตรง** — กันผลประโยชน์ทับซ้อน
- ใส่ตัวเลขจริงในชีต "เซลส์" และ "คำนวณกำไรต่อคัน" ของ CRM เพื่อตรวจว่าคุ้ม

## 7. ข้อมูลส่วนบุคคล (PDPA) — สิ่งที่ผู้ช่วยขายต้องทำ

- ใช้ LINE OA และ CRM ของบริษัทเท่านั้น **ห้ามใช้ LINE ส่วนตัวคุยกับลูกค้า**
- ห้ามเก็บรูปบัตรประชาชน/เล่มไว้ในมือถือส่วนตัวเกินจำเป็น ลบหลังปิดดีล
- ห้ามแคปแชทลูกค้าไปโพสต์ที่ไหน
- ลูกค้าขอให้ลบข้อมูล → แจ้งหัวหน้าทันที
