# เอกสารธุรกิจ รถไว (RodWai)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `RodWai-CRM.xlsx` | CRM ติดตามลีดทุกคัน + ราคาเสนอจากเต็นท์ + รายชื่อเต็นท์ + ผลงานผู้ช่วยขาย + **เครื่องคิดกำไรต่อคัน** + แดชบอร์ด อัปโหลดขึ้น Google Drive แล้วเปิดด้วย Google Sheets ได้เลย |
| `SOP-ผู้ช่วยขาย.md` / `.docx` | คู่มือการทำงานของผู้ช่วยขาย 7 ขั้นตอน เช็กลิสต์ตรวจเอกสาร สัญญาณอันตราย ข้อความ LINE สำเร็จรูป และ KPI |
| `ข้อตกลงเต็นท์พาร์ทเนอร์-ร่าง.md` / `.docx` | **ร่าง**ข้อตกลงกับเต็นท์ (ค่าบริการ, ห้ามติดต่อข้ามหัว, การชำระเงิน, PDPA) + ใบยืนยันการซื้อรถ — ต้องให้นักกฎหมายตรวจก่อนใช้ |
| `tools/build_crm.py` | สคริปต์สร้างไฟล์ CRM ใหม่ (ถ้าต้องการแก้โครงสร้าง) |

ข้อมูลในไฟล์ CRM เป็นข้อมูลส่วนบุคคล — เมื่อเริ่มใช้งานจริง ให้เก็บใน Google Sheets ที่จำกัดสิทธิ์ ไม่ commit ข้อมูลลูกค้าเข้า repository นี้
